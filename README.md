# Sales Data Visualization

## Project Objective
The objective of this project is to analyze sales data and present meaningful insights using different data visualization techniques.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset
This project uses simulated sales data created for learning and demonstration purposes.

## Visualizations
1. Total Sales by Product Category
2. Monthly Sales Trend
3. Sales Contribution by Category

## Key Insights
- Electronics generated the highest total sales among the product categories.
- Sales generally increased over the months, with the highest sales recorded in June.
- Electronics contributed the largest share of total sales.

## Conclusion
The visualizations help in understanding sales performance across different product categories and months. The project demonstrates how Python libraries such as Pandas, Matplotlib, and Seaborn can be used to analyze and visualize sales data.
